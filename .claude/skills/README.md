# Skills del repositorio

Instrucciones que los agentes de código cargan al trabajar en SIGBA. Vienen del perfil
del usuario y de `ruta`, adaptadas a este proyecto: hablan de módulos, fronteras, RLS y
outbox, no de las rutas de otro repositorio.

| Skill                                | Para qué                                                                   |
| ------------------------------------ | -------------------------------------------------------------------------- |
| `ponytail`                           | Buscar la solución más simple que cumpla el comportamiento pedido.         |
| `thermo-nuclear-code-quality-review` | Auditoría de mantenibilidad antes de abrir o mezclar una PR.               |
| `stop-slop`                          | Quitar patrones de redacción de IA de cualquier texto que lea una persona. |

`ponytail` y `thermo-nuclear-code-quality-review` llevan una sección propia de SIGBA: la
primera lista lo que **no** se puede simplificar porque el documento de arquitectura lo
paga a propósito; la segunda añade lo que hay que revisar además en este dominio.
