# SBA-10 · Cuentas de operación

Entregable de [SBA-10](https://linear.app/iuva/issue/SBA-10). `cuentas.md` registra
los cinco servicios de infraestructura de SIGBA: uso, titular, plan, acceso del equipo
y recuperación.

Es un registro provisional. Las cuentas están a nombre de Mariana Colorado hasta que se
defina el correo institucional que pide ADR-03.

Contiene el usuario de GitHub titular de cada cuenta, el proyecto de Neon, las
organizaciones de Sentry y Fly.io y la vía de recuperación de cada servicio. No contiene
contraseñas, tokens, llaves, códigos 2FA, correos ni el dominio del tenant de Auth0: esos
valores viven en la configuración de cada servicio.
